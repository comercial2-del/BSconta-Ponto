# BSconta+ RH — Visual System v2

Esta versão mantém as funcionalidades e fluxos existentes e adiciona um sistema visual compartilhado em `css/theme-v2.css`.

Principais ajustes visuais:
- hierarquia de página mais clara;
- menos peso visual em bordas e sombras;
- azul BSconta como cor principal de ação;
- cores semânticas reservadas para estados;
- cards, tabelas, formulários e botões com escalas consistentes;
- sidebar mais enxuta e navegação mobile preservada;
- login redesenhado;
- microinterações, estados de foco e respeito a `prefers-reduced-motion`;
- comportamento responsivo refinado para desktop, tablet e celular.

A lógica JS e a organização funcional das telas existentes foram preservadas.

## Refresh de navegação v2.2
- Sidebar desktop agora pode ser recolhida e mantém a preferência no navegador.
- Cada tela recebe contexto visual no topo e acento semântico discreto por módulo.
- Barra de filtros foi reorganizada como toolbar responsiva.
- Navegação mobile usa quatro atalhos prioritários + menu Mais para não esconder módulos.
- Tabelas e cards receberam tratamento mais leve, com melhor densidade e estados de interação.
