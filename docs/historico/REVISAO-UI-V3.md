# BSconta+ RH — Revisão UI/UX v3

Esta versão mantém a lógica, rotas e módulos existentes e aplica uma camada visual refinada sobre todo o sistema.

## Escopo visual
- Design system compartilhado para todas as páginas.
- Hierarquia de títulos e cabeçalhos por módulo.
- Sidebar mais limpa, com contexto do módulo ativo e modo recolhido.
- Header e controles com maior consistência.
- Cards, KPIs, tabelas, filtros, tabs, formulários e modais refinados.
- Estados de foco, hover, active e feedback visual.
- Melhorias de responsividade desktop/tablet/mobile.
- Navegação mobile preservada e refinada.
- Cores semânticas reservadas para status e ações importantes.
- Redução de sombras e bordas para uma interface mais leve.

## Validação realizada
- JavaScript validado com `node --check`.
- Estrutura HTML analisada e caminhos locais conferidos.
- Todos os módulos RH e Colaborador continuam presentes.
- Nenhuma lógica de negócio foi removida deliberadamente.
